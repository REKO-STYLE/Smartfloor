Proyecto SmartFloor · UTP

Cada paso puede generar electricidad

Un piso especial aprovecha el movimiento de las personas al caminar para producir energía eléctrica, sin usar cables ni baterías externas.

Pasos: 0  ·  Energía acumulada: 0 mJ

¿Cómo funciona?

El sistema convierte el movimiento del paso en electricidad en cuatro etapas sencillas.

1. Pisas el piso

Tu peso presiona una pequeña losa que baja apenas unos milímetros al caminar.

2. Un engranaje amplifica el movimiento

Un mecanismo de cremallera-piñón convierte ese pequeño descenso en muchas vueltas rápidas.

3. Un imán se mueve dentro de una bobina

El giro mueve un imán a través de una bobina de alambre de cobre, muy cerca y muy rápido.

4. Se genera electricidad

Ese movimiento induce una corriente eléctrica, capaz de encender un LED o cargar un pequeño sensor.

Lo que se espera del prototipo

Estimaciones teóricas para una losa de laboratorio de 30×30 cm, antes de las pruebas físicas.

¿Por qué importa? En lugares muy transitados —estaciones, centros comerciales, campus— miles de pisadas se pierden como energía desaprovechada. Aunque la eficiencia hoy es baja, este piso podría alimentar luces LED o sensores sin necesidad de cableado, usando algo que ya ocurre: caminar.

Basado en el avance de proyecto "Diseño de un piso generador de energía mediante inducción electromagnética (Smart Floor)", UTP.
